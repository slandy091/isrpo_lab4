# Geometric Lib

## Описание

Библиотека для выполнения некоторых базовых геометрических операций

## Функции

### Операции для окружности (`circle.py`)

#### `area(r)`

Считает площадь окружности по радиусу

**Параметры:**

- `r` - число (радиус окружности)

**Пример использования:**

```
s = area(3)
print(s) # 28.274333882308138
```

#### `perimeter(r)`

Считает периметр окружности по радиусу

**Параметры:**

- `r` - число (радиус окружности)

**Пример использования:**

```
s = perimeter(3)
print(s) # 18.84955592153876
```

### Операции для квадрата (`square.py`)

#### `area(a)`

Считает площадь квадрата по стороне

**Параметры:**

- `a` - число (сторона квадрата)

**Пример использования:**

```
s = area(3)
print(s) # 9
```

#### `perimeter(a)`

Считает периметр квадрата по стороне

**Параметры:**

- `a` - число (сторона квадрата)

**Пример использования:**

```
s = perimeter(3)
print(s) # 12
```

### Операции для прямоугольника (`rectangle.py`)

#### `area(a, b)`

Считает площадь прямоугольника по двум сторонам

**Параметры:**

- `a` - число (одна сторона прямоугольника)
- `b` - число (вторая сторона прямоугольника)

**Пример использования:**

```
s = area(3, 4)
print(s) # 12
```

#### `perimeter(a, b)`

Считает периметр прямоугольника по двум сторонам

**Параметры:**

- `a` - число (одна сторона прямоугольника)
- `b` - число (вторая сторона прямоугольника)

**Пример использования:**

```
s = perimeter(3, 4)
print(s) # 14
```

### Операции для треугольника (`triangle.py`)

#### `area(a, h)`

Считает площадь треугольника по стороне и опущенной на неё высоте

**Параметры:**

- `a` - число (сторона прямоугольника)
- `h` - число (высота опущенная на сторону прямоугольника)

**Пример использования:**

```
s = area(3, 4)
print(s) # 6
```

#### `perimeter(a, b, c)`

Считает периметр треугольника по трём сторонам

**Параметры:**

- `a` - число (одна сторона треугольника)
- `b` - число (вторая сторона треугольника)
- `c` - число (третья сторона треугольника)

**Пример использования:**

```
s = perimeter(3, 4, 5)
print(s) # 12
```
